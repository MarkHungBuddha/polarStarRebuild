# 情境內容作者筆記

> 本文件的機制與門檻說明適用於現行題庫。改寫五段偏向作答、補齊每組三個情境時，先讀 [新版規格](preference-strength-spec.md)；新版不沿用接受條件門檻或分配量推定強度。

供後續 implementer 使用；非題庫定稿、非心理測量驗證。依主 repo 的正式規格、GLOSSARY 與共同價值 ADR。只提供工作情境文案建議，實作者須配合實際機制與答案契約調整。

## 共通原則

- 每題明確說出兩邊的好處與代價。不可用「生病家人／出去玩」等道德壓力充當價值衝突，也不可用違法、明顯失禮作為另一邊。
- 背景用「假設你是這次…」交代，不要求已有房屋、伴侶、孩子或主管身分。
- 主導權指最後決策權與資源控制，不是善意影響或助人。普遍關懷需包含超出親近圈的群體／環境，不縮成個人公平感。
- 題面不揭露核心價值；以下價值標記僅供內容 metadata 與結果使用。主標題不要直接叫「自主／安全」。
- 滑桿先報原始接受條件；只有在 `src/scenarios/slider-leans.ts` 設定的兩個門檻之外才算偏向一邊（ADR 0003），門檻之間不算。
- 六題滑桿的門檻（2026-10-23 專案負責人採用）：slot01 兩題 ≤3 偏自主、≥12 偏安全穩定；slot07-study ≤2 偏成就、≥8 偏享受生活；slot07-weekends ≤2 偏成就、≥7 偏享受生活；slot10-accessible ≤1 偏普遍關懷、≥5 偏成就；slot10-environment ≤1 偏普遍關懷、≥4 偏成就。
- 分配題以「本題分給 A 較多」作為偏向；均分只報實際配置。不得說成偏好強度、穩定人格或跨情境特徵。
- 刪稿兩段都要完整，送出前只留一段；每段需同時交代自己選擇與所放棄，不讓使用者靠客套話同時保留雙方。
- Binary／strike 的方向來自明確選項 metadata，不從文字情緒或模型猜測。結果先引用選擇證據，再依第一幕是否有明確順序決定相符／不同。

## Ticket 06：分配機制（槽 3、6、14，各二變體）

### 槽 3：自主／照顧身邊的人

- **slot03-evenings — 六個下班時段**：接下來三週有六個晚上，每晚兩小時。A 留給自己規劃的攝影小誌；B 陪一位正在轉職的好友練面試。好友另有其他協助，沒有緊急危機。分給 A 多一晚就少一晚陪練；分給 B 多一晚就少一晚推進自己的方向。題目說「六晚全部分完，兩邊可分零」。結果報「你把四晚留給自己的小誌、兩晚用來陪朋友練習」，不報倍數強度。
- **slot03-weekend — 四個週末下午**：A 自選路線做個人散步紀錄；B 陪熟識的長輩學手機整理相片。長輩已有日常支援，只是珍惜由你陪伴的時間。四個下午全分完。避免以「不幫會出事」增加壓力；A 必須是自選內容，不是獎勵消費，以免變享樂。

### 槽 6：探索刺激／成就

- **slot06-learning — 六次進修機會**：A 選從沒試過的跨領域短課（木工、即興、聲音採集）；B 練熟悉的工作技能，完成一份可公開展示的作品。課程與練習均有安排且不能同時完成；每次兩小時，分六次。A 的好處是新鮮探索，代價是作品進度；B 的好處是完成具體成果，代價是暫停新嘗試。
- **slot06-community — 六個活動時段**：社群開放報名。A 嘗試六種不同難度的活動；B 反覆練同一項你已選定的技能，完成月底成果展示。不是要求使用者真有社群或競賽經歷。避免把 A 寫成「隨便玩」而 B 寫成「上進」，兩邊都需投入。

### 槽 14：安全穩定／普遍關懷

- **slot14-preparation — 六個準備時段**：A 整理自己的備援資料、緊急聯絡清單與家用防災物品，增加個人生活可預期性；B 參與社區多語與無障礙防災資訊整理，讓不熟悉中文／行動不便者取得資訊。無立即災情；兩件事均可延後。分六個一小時時段。B 不只是幫熟人，A 也非自私選項。
- **slot14-workflow — 六個改善時段**：你可自行安排六個工作改善時段。A 建立自己負責工作的備援與交接流程，降低臨時中斷；B 協助將公開活動資訊做成更易讀、可被不同需求使用者取得的版本。主管同意兩項均可做，無一方是規定責任。避免 A 被寫成純成就、B 變單純遵規；A 強調降低不確定，B 強調圈外多元需求。

## Ticket 07：滑桿內容（補槽 1 第二題，槽 7、10 各二題）

本筆記不重寫原型槽 1；其第二題仍需由 slider implementer 依既有契約補寫。以下四題均為條件，不判勝負。

### 槽 7：享受生活／成就

- **slot07-study — 進修也要留白**：假設你想完成一個自己重視的專業成果，八週內每週需投入固定時數；這會壓縮原有休閒。問「每週至少保留幾小時純休閒，你才考慮接受這個八週安排？」刻度 0–12 小時、整數，原始單位保留。結果：「你希望每週至少保留 X 小時休閒，再考慮八週成果計畫。」不說 X 高就享樂勝出。
- **slot07-weekends — 六週的作品集**：朋友提供六週作品集共學，每週末原本有一整天能自在吃飯、散步、休息；參加會占去部分時間。問「每個週末至少保留幾小時不安排目標的時間，你才考慮加入？」0–10 小時。背景交代參加是自選且無工作強制；不把休閒寫成偷懶。

### 槽 10：成就／普遍關懷

- **slot10-accessible — 多做一個人人看得懂的版本**：假設你正在完成一份可展示個人能力的公開教學成果；另做無障礙、易讀版能讓更多不同需求的人使用，但會延後個人成果發表。問「至少多給幾週，你才考慮同時做易讀版？」0–8 週。結果只報所需額外時間，不把較短解讀成更關懷或更有能力。避免暗示只做一般版就是歧視；一般版仍符合基本可用性。
- **slot10-environment — 個人成果與共同資料**：你可用一份成果參加自選的作品徵件；另整理可供不同地區團體參考的環境資料會占用作品修改時間。問「至少延長幾週徵件準備期，你才考慮兩項都做？」0–6 週。這是對期限條件的回報，不能當兩價值直接比較。不得暗示資料確有科學效益或量化環境成效；只是情境中的用途。

## Ticket 08：刪稿內容（補槽 2 第二題，槽 9、12 各二題）

本筆記不重寫原型槽 2。**待確認：** 槽 2 第二題 `slot02-cleaning`（`src/scenarios/strike.ts`）在本筆記沒有草稿時由 agent 自行撰寫，文案尚未經作者確認。每個草稿選項都保留完整句子，實作時明確把「刪掉哪段」與「留下哪段」分開。

### 槽 9：享受生活／遵守規範

- **slot09-quiet-hours — 聚會的散場時間**：你參加共用空間的小型聚會，借用時大家約定九點停止活動。現在氣氛很好，場地方另允許付費延長，無違法噪音問題；團體原約定仍是九點。A 留下：「我想多留半小時把這段相聚享受完；我願意分攤延長費，也接受明天少些休息。」（享受）B 留下：「我想照我們原先約好的九點散場；雖然正聊得開心，我會把後面的話留到下次。」（規範）A 是偏離共同約定，不寫成違法或擾鄰。
- **slot09-phone-free — 無手機的晚餐**：同事小聚約好用餐不拿手機，無工作或家庭急事；你很想拍眼前難得的甜點與朋友合照。A：「我想拍幾張留下今晚的愉快，再收起手機；我知道這偏離了原先的餐桌約定。」B：「我先照約定把手機收著，專心吃完；這次就不留下甜點和合照了。」避免把 A 寫成整晚滑手機，或 B 寫成道德高地。拍照須已徵得朋友同意。

### 槽 12：主導權／照顧身邊的人

- **slot12-project — 你熟悉的夥伴想主導**：你與熟識夥伴共同做自願小專案，原本由你定最後方向；夥伴希望練習主導，分工無契約衝突。A：「這次我想保留最後定案權，讓方向依我的判斷推進；我知道這會少給你一次主導的練習。」（主導權）B：「這次由你定最後方向，我提供需要的支援；即使最後方案不是我最想要的，我也願意讓出這個位置。」（照顧）不是 A 幫助效率與 B 拋棄責任；二者都繼續投入。
- **slot12-outing — 熟朋友的活動籌備**：朋友群每次都由你控預算與行程；一位親近朋友想試著安排，這次無人有特殊安全或無障礙需求。A：「這次預算與行程的最後決定我仍想自己掌握；你可以提建議，但我會負責定案。」B：「這次我願意讓你決定預算內的行程，配合你的安排；我會放下自己想掌握細節的習慣。」A 的正面是你重視自己的決策掌握，代價是親近者少一次被支持；不要硬加「因為只有我有能力」道德化能力差異。

## Ticket 09：其餘二選一（槽 5、8、11、13、15，各二題）

### 槽 5：探索刺激／傳承

- **slot05-festival — 同一天的兩場活動**：假設你熟悉的社區每年有一場傳統工藝日，你多年來都參加；今年同日有只辦一次的陌生領域體驗。A 新體驗：接觸全新活動，放棄今年延續慣例；B 工藝日：延續與文化的連結，放棄這次新鮮機會。兩場都無工作責任或人情催促。
- **slot05-holiday — 連假怎麼過**：你有一段自行安排的連假；A 去沒去過的地區參加新型體驗，B 回到自己熟悉的節慶活動學一段老技藝。不是返鄉陪家人題；明確排除對親近者的照顧義務，讓焦點保留在新奇與文化延續。

### 槽 8：享受生活／照顧身邊的人

- **slot08-evening — 訂好的休息夜**：你原本留一晚看期待很久的電影；熟朋友想找你聊最近的工作轉換，沒有危機，也可另找人聊。A 保留休息夜，明晚再回覆；B 今晚陪聊，放棄這次完整休閒。不要把電影寫成可隨時無損補看，或朋友設定為只有你能救。
- **slot08-day-off — 半天的空檔**：你唯一空出的半天原計畫去喜歡的展覽；親近朋友想請你陪挑面試衣服，也能自行處理。A 享受展覽，這次不陪；B 陪朋友準備，放棄展覽。問選擇而非「應該做什麼」，不要加「不陪就失去工作」。

### 槽 11：主導權／普遍關懷

- **slot11-fund — 小額活動預算**：假設你爭取到一筆可自行規劃的社區活動預算；可依你完整方案使用，或把一部分決策交給不同背景的參與者，納入原方案沒涵蓋的需求。A 保留全部定案權、完整實現自己的規劃，代價是較少讓不同需求改變方向；B 讓不同背景代表共同決定部分資源，擴大需求涵蓋，代價是自己無法完全掌握。不要把 A 寫成不透明挪用、B 寫成法律要求。結果只描述本情境選擇，無治理效果宣稱。
- **slot11-event — 一場公開分享會**：你有權決定公開活動的名額與主題，兩種都符合主辦規則。A 保留主題和名額配置的最後決定，完整實行自己的構想；B 讓部分名額與內容由不同使用需求的代表共同安排，讓活動涵蓋更多處境，但接受安排偏離自己原意。主導權的好處需誠實表達為控制與自己的判斷，不能偷換成成就；普遍關懷透過不同群體福祉呈現，非只對朋友好。

### 槽 13：主導權／傳承

- **slot13-club — 誰決定今年的形式**：假設你接任自願社團的活動召集，章程允許你調整形式；老成員希望沿用傳下來的儀式。A 使用自己的定案權重新安排，接受中斷慣例；B 讓既有儀式決定流程，即使自己少些主導空間。不要把舊儀式設定成低效率、有害或排斥群體。
- **slot13-exhibition — 展示的安排權**：地方工藝展邀你負責策展，你可主導呈現，或沿用師傅們歷年的展示次序與介紹方式。A 依你完整構想定案，放下部分傳承形式；B 延續既有形式，接受自己不能完全定方向。新方案不是更刺激的技術，重點是誰掌握方向；舊方案不等於規定必須遵守。

### 槽 15：遵守規範／傳承

- **slot15-meeting — 新共識與舊慣例**：自願社團新通過每次輪流主持；這次恰好是多年固定由資深成員主持的紀念聚會。兩種都可選，沒有法律或安全問題。A 照新共同規則輪流，暫停紀念聚會舊慣例；B 保留紀念聚會的老主持方式，這次偏離輪值共識。需明確「新規則尚未設例外」，但不把 B 寫成欺瞞。
- **slot15-reuse — 聚會的餐具**：小型文化社群新約定活動統一使用可清洗公用餐具；多年來某次節慶總用各自帶來、具有傳承意義的器皿。公用餐具與個人器皿都安全，環境代價相近。A 用公用餐具遵守新約定，少一次傳承器皿儀式；B 沿用帶器皿的慣例，這次不照新約定。排除環保與衛生優劣，避免把題目變普遍關懷／安全。

## 跨票檢查重點

2. 槽 11 的權力與包容、槽 15 的規範與傳統尤其難寫，作者應清楚交代兩個「合理正當的好處」，避免把選擇壓成善惡。
3. 二選一的兩個變體在票 09 包含十題；票 05 另補槽 4 第二題。不要重複定義相同變體 ID。
4. 票 07、08 各需補原型槽 1、2 的第二變體。本筆記未提供這兩題定稿，需依原型現有文案與 schema 另補。
