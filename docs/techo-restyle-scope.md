# 261024 手帳感調整範圍

確認日期：2026-10-24。狀態：使用者已確認本文件的四項範圍決策；尚未實作。

## 依據與優先順序

視覺參考為 [手帳感 UI 規格](../261024/northstar-techo-spec.md) 與 [設計稿](../261024/北極星%20手帳感.html)。本文件記錄將設計套用到現有產品時的範圍調整；與設計稿衝突時，以本文件為準。領域用詞沿用 [GLOSSARY.md](../GLOSSARY.md)，結果解讀沿用 [既有決策](adr/)。

本次以視覺調整為主，保留題型、計分與資料行為。原規格中尚未決定的第三選項、自動換題、單一主價值、最大名次落差等，不納入本次。

## 已確認範圍

1. 主題預設跟隨系統，用太陽／月亮開關改成淺色或深色，記住使用者偏好；預設藍墨水與粉色紙膠帶。本次不提供自訂墨水色或紙膠帶色的介面。
2. 保留現有題目分享連結及其不含答案的行為。結果圖片匯出留待後續獨立處理，本次不新增圖片分享按鈕。
3. 手機採單欄。首頁與一般情境採窄欄；第一幕、結果頁及需要較大操作空間的既有題型，在桌面保留適合操作與比較的寬度，不全站強制套用 440px。
4. 首頁保留簡短工具說明，新增可開關的「關於這份題目」說明區，放置完整限制，不新增獨立路由。結果頁保留與排名解讀直接相關的提醒。

## 各畫面的套用方式

| 畫面 | 本次調整 | 保留的功能 |
|---|---|---|
| 首頁 | 點格紙、紙卡、紙膠帶、字體、按鈕、簡短說明與可開關說明區 | 開始、續答、分享題組衝突提示與儲存失敗提示 |
| 第一幕 | 依共同視覺規則補齊分類與排序畫面 | 分類按鈕與自訂價值；排序改用拖曳，也可用鍵盤操作；不能並列 |
| 第二幕 | 情境紙卡、進度、控制元件及回饋的配色與排版 | 二選一、刪稿、滑桿與分配的既有操作、確認答案及返回修改流程 |
| 結果 | 以手帳視覺呈現摘要、比較與詳細證據 | 兩幕各自的前三名、並列、次數與分母、逐題證據、修改答案與回顧第一幕 |
| 共用區域 | 主題選擇與一致的字體、間距、焦點及按鈕樣式 | 題目分享、本機紀錄清除與相關提示 |

設計稿的單選卡片僅作視覺參考，不取代現有具體操作元件。結果頁不改成單一主價值、前五名長條或「最大落差」解讀；文字使用「作答差異」，不將情境答案說成真實行為。

## 實作與驗收邊界

- 題庫、計分門檻、並列規則、答案結構、題組版本與抽題方式維持既有行為。
- 續答、已看題目紀錄、既有分享連結與重新開始／清除紀錄的差異均須保留；主題偏好獨立於作答資料。
- 採用設計規格的顏色 token、手寫標題與無襯線內文、紙張背景及裝飾限制。旋轉只作用於背景或裝飾，文字保持水平。
- 主題跟隨系統及手動切換均須可用；儲存不可用時有合理預設，初次載入避免錯誤主題閃爍。
- 檢查 320px、390px 與桌面版，避免橫向溢出；長價值名稱、並列及自訂價值不能被截斷。
- 保留鍵盤操作，提供清楚焦點；點擊區至少 44 × 44px，進度有文字與可讀取的數值，減少動態效果設定下停用位移動畫。
- 視覺驗收涵蓋所有題型、第一幕、摘要與詳細結果，以及續答與錯誤提示；行為驗收使用既有測試，新增主題與說明區的必要測試。

## 現況比對補充

原規格將第一幕描述為拖曳排序，改版時先保留名次選單；2026-10-24 依使用者回饋改回拖曳排序並取消並列（ADR 0004），同時把主題下拉選單換成太陽／月亮開關。原規格提及可沿用 Noto 自架流程，目前樣式實際使用 Google Fonts，不假設已有自架字型流程。

改版當時沒有需要新增的領域術語或難以逆轉的架構決策；之後取消並列時更新了詞彙表，並新增 ADR 0004。後續規格與工作項目應引用本文件，避免再次把設計稿的示意功能當成已同意需求。
