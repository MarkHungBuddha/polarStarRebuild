# 手帳感工作項目提案

來源：GitHub 規格 #17。狀態：使用者指示依整份規格實作，已發布為子議題 #18–#22，並建立原生阻擋關係。

每張票都包含可操作的畫面與相關驗收，沿用既有 Playwright 測試。所有票共同遵守：不改題庫、計分、答案格式、題組版本與資料行為；依 261024 規格及已確認範圍處理視覺，採臺灣用語。

## 01：手帳感首頁、三種主題與題目說明

### Parent

https://github.com/MarkHungBuddha/polarStarRebuild/issues/17

### What to build

使用者開啟網站即可看見手帳感首頁，選擇淺色、深色或跟隨系統，展開完整題目說明，並開始或接續作答。隨此流程建立後續畫面共用的視覺樣式與主題行為；其他既有畫面在主題切換後仍須可讀、可操作。

### Acceptance criteria

- [ ] 首頁具備點格紙、紙卡、規定字體與預設藍墨水／粉色紙膠帶；文字保持水平、裝飾數量符合規格。共同樣式以 token 表達，控制元件有清楚焦點及停用狀態。
- [ ] 預設跟隨系統，可手動選擇淺色或深色並保存；恢復跟隨系統後可回應系統設定變更。
- [ ] 首次呈現套用正確主題；儲存失敗及慢速字型載入不阻止使用，備援文字可讀。
- [ ] 主題偏好獨立於作答資料，切換不改作答位置或答案；其他尚未完成視覺調整的畫面仍可使用。
- [ ] 首頁保留簡短說明，可用鍵盤開關「關於這份題目」，狀態可辨識，不新增路由。
- [ ] 開始、續答、分享題組衝突與儲存失敗提示維持原有功能並可閱讀。
- [ ] 320px、390px 與桌面淺深色檢查通過，沒有橫向溢出；點擊區至少 44 × 44px，字體、對比與減少動態效果符合規格。
- [ ] 新增主題及說明區的瀏覽器行為測試，執行受影響的既有測試與專案檢查。

### Blocked by

無，可先開始。

## 02：第一幕分類與排序套用手帳風格

### Parent

https://github.com/MarkHungBuddha/polarStarRebuild/issues/17

### What to build

使用者能在手帳風格的第一幕完成分類、自訂價值、排序與並列，再進入第二幕；回訪仍能接續相同資料。

### Acceptance criteria

- [ ] 分類及排序畫面沿用共同視覺，保留分類按鈕、名次選單及自訂價值，不新增拖曳排序。
- [ ] 長價值名稱、自訂價值與並列完整顯示；手機單欄，桌面保留足夠操作空間。
- [ ] 可用鍵盤完成分類與排序；焦點、點擊區及提示符合共同規格。
- [ ] 從第一幕進入第二幕、返回調整及重新開啟後續答，都保留原有分類、名次與自訂價值。
- [ ] 320px、390px 與桌面淺深色視覺驗收通過；既有第一幕與續答測試及專案檢查通過。

### Blocked by

01：使用共同視覺與主題行為。

## 03：情境框架、二選一與刪稿套用手帳風格

### Parent

https://github.com/MarkHungBuddha/polarStarRebuild/issues/17

### What to build

使用者在手帳風格情境畫面讀題、辨識進度，以既有二選一或刪稿操作確認答案，並可返回修改。共同情境框架同時保留其他題型的可用性。

### Acceptance criteria

- [ ] 情境文字、紙卡、題號、進度、確認按鈕與返回操作使用共用視覺；長情境依規格改用無襯線內文。
- [ ] 進度同時有可見文字與輔助技術可讀取的數值，不單靠顏色。
- [ ] 保留二選一與刪稿的既有具體操作和鍵盤替代方式，不改成設計稿中的 radio 卡片。
- [ ] 未確認草稿不算提交；確認、返回與重新確認均維持原有答案語意。
- [ ] 減少動態效果時停用位移，裝飾不遮住互動區。其他題型放入共同框架後仍可操作。
- [ ] 320px、390px 與桌面淺深色驗收涵蓋不同情境內容、已選與未選狀態，無橫向溢出且點擊區符合要求。
- [ ] 既有二選一、刪稿、互動與確認答案相關測試及專案檢查通過。

### Blocked by

01：使用共同視覺與主題行為。

## 04：滑桿與時間分配套用手帳風格

### Parent

https://github.com/MarkHungBuddha/polarStarRebuild/issues/17

### What to build

使用者在手帳風格的情境框架中操作存錢筒、時鐘、月曆與活動配置，調整接受條件或分配資源，再確認及回頭修改。

### Acceptance criteria

- [ ] 存錢筒、時鐘、月曆與活動配置均完成淺深色與字體調整，數值、單位及操作回饋清楚可讀。
- [ ] 保留既有點選、拖曳與鍵盤操作，原有可選範圍、步長、分配限制及答案確認方式不變。
- [ ] 未確認操作不覆寫已確認答案；返回修改、續答與最終計分維持既有行為。
- [ ] 手機單欄，複雜控制元件在桌面保留足夠空間；320px、390px 與桌面無溢出、遮擋或文字截斷。
- [ ] 所有控制形式及邊界值均完成淺深色視覺驗收；焦點、點擊區與減少動態效果符合規格。
- [ ] 既有滑桿、分配、具體互動及相關續答測試與專案檢查通過，不更改門檻或題組版本。

### Blocked by

03：使用完成調整的共同情境框架、進度及確認區。

## 05：結果回顧與題目分享套用手帳風格

### Parent

https://github.com/MarkHungBuddha/polarStarRebuild/issues/17

### What to build

使用者能閱讀手帳風格的結果摘要、比較兩份前三名、查看及修改逐題答案，並沿用題目分享、重新開始與清除本機紀錄。

### Acceptance criteria

- [ ] 摘要及詳細回顧均完成手帳視覺；保留兩份前三名、並列、選擇次數與分母，不新增單一主價值或最大落差解讀。
- [ ] 保留逐題證據、自訂價值、回顧第一幕及修改答案流程；修改後結果更新並回到原有回顧位置。
- [ ] 長名稱、多項並列與無偏向答案均可閱讀；結果解讀限制仍清楚可見，使用既有領域用詞。
- [ ] 題目分享及清除紀錄區使用共同視覺，連結仍只含題組；不新增圖片匯出。
- [ ] 分享連結複製成功與失敗提示、續答相容性、重新開始保留已看紀錄及清除作答紀錄的既有行為均不變。
- [ ] 手機單欄，桌面保留比較空間；320px、390px 與桌面淺深色畫面皆無文字截斷或橫向溢出，鍵盤及點擊區符合規格。
- [ ] 使用固定題組與輸入核對結果；既有結論、分享、保存及回顧修改測試與專案檢查通過。

### Blocked by

01：使用共同視覺與主題行為。既有第一幕及題型已可操作，因此不等待 02、03、04 的視覺完成。

## 依賴與整體驗收

依賴：01 → 02、03、05；03 → 04。這些是前置完成條件，不代表要求同時修改共用檔案。

各票自行完成行為與視覺驗收。全部完成後，以完整十五題流程檢查全站淺深色、各尺寸、主題切換與保存相容性，並執行完整測試及專案檢查；不另建立只寫測試的水平工作項目。實作順序不改變這項共同完成條件。
