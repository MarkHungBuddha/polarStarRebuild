# 場景移動：開發審閱題

這題沿用專案負責人於 2026-10-26 試玩確認的休息夜場景，作為 #79 的正式互動機制切片。題面來源是 AI 草稿；六題試玩確認不代表完整 45 題已通過審閱，也不表示題目經過心理測量驗證。

- 題目識別：`redesign-slot08-evening`；配對：享受生活／照顧身邊的人。
- 操作與限制：將人物從走廊移入沙發區或餐桌區。今晚只夠完整做一件事，兩件都可以另約；朋友沒有危機，也能找別人聊。
- 雙方代價：看電影會延後陪朋友談話；陪朋友會延後期待的電影。保留完整休閒與親近者的陪伴各有好處，不加入安全風險或只有作答者能幫忙的條件。
- 方向規則：有效位置明確代表「今晚看電影」或「今晚陪朋友」，每題最多計對應價值一次。走廊尚未形成決策；落在場景外保留原位置，不自動選最近一側。不使用距離、路徑、速度或移動次數推算偏好。
- 原始紀錄：保存有效位置的識別，結果引用該位置的具體行動與後果。草稿修改須再次確認；「目前無法決定」另行保存，不能用走廊位置冒充。
- 後續內容審閱：原型與舊上線的電影題代價不同；本題兩件事都可改約，不能混入舊題「電影即將下檔、不能補看」的設定。擴充其他場景時，位置名稱、行動與後果均由 registry 提供。
