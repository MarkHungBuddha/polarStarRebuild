# 09：補齊其餘五個二選一槽位

## What to build

使用者能完成原型以外的五種二選一價值對，從閱讀具體代價到確認、回改與結果對照皆完整可用。

## Acceptance criteria

- [ ] 完成槽位 5（探索刺激／傳承）、8（享受生活／照顧身邊的人）、11（主導權／普遍關懷）、13（主導權／傳承）、15（遵守規範／傳承），各兩個變體，共十題。
- [ ] 每題提供充分的台灣日常背景，兩邊皆合理、有所保護也有所放棄，不要求特定家庭經歷，不展示背後價值名稱。
- [ ] 所有新增題目都能從介面選擇、明確確認、返回修改並核對結果；不加入第三選項、倒數或速度加權。
- [ ] 結果遵守明確先後與答案方向的共同規則，不推論人格、原因或跨情境穩定特徵。
- [ ] 新變體有全域唯一且穩定的識別，同槽機制一致；若保存與分享已完成，新增變體需自然遵守其契約。
- [ ] 驗證新增槽位的代表性完整路徑，確認相符、不同與並列情況的外部行為，檢查十題內容契約並完成建置。

## Blocked by

- 02：以代價滑桿表達接受條件。
- 03：加入刪稿並完成三關原型。

先完成三關原型，再擴充二選一內容；不依賴分享或其餘內容擴充票。
