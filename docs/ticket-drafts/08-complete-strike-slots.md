# 08：補齊三個刪稿槽位

## What to build

使用者可在完整 MVP 所需的三個刪稿槽位，以刪除一段回覆表達不同價值間的取捨，結果能核對保留的內容及第一幕位置。

## Acceptance criteria

- [ ] 將槽位 2（自主／遵守規範）補至兩變體，完成槽位 9（享受生活／遵守規範）及 12（主導權／照顧身邊的人）各兩變體；本票新增五題，刪稿共六題。
- [ ] 每題提供兩段完整合理的回覆、雙方代價與明確答案語意，不以失禮或不道德的一段製造標準答案。
- [ ] 所有新增題目皆可從介面完成刪稿、確認、回改及結果核對；不要求畫線手勢。
- [ ] 只有第一幕有明確先後、所留回覆方向也明確時，才呈現相符／不同；並列或方向不明時直接描述。
- [ ] 新變體有全域唯一且穩定的識別，同槽機制一致；若保存與分享已完成，新增變體需自然遵守其契約。
- [ ] 驗證新槽位的完整作答到結果路徑、兩種保留方向及鍵盤操作，檢查新增內容一致性並完成建置。

## Blocked by

- 02：以代價滑桿表達接受條件。
- 03：加入刪稿並完成三關原型。

先完成三關原型，再擴充刪稿內容；不依賴其他內容擴充票。
