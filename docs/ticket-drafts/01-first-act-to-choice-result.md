# 01：打通第一幕到單題二選一結果

## What to build

使用者能閱讀反思工具說明，分類與排序十個共同核心價值（含並列），加入自訂價值，直接完成槽位 4 的一題二選一，並在簡短結果中核對自己的第一幕位置與最後確認的選擇。這是第一條可完整展示的路徑，也建立後續情境機制可沿用的作答與結果契約。

## Acceptance criteria

- [ ] 依術語表與共同價值 ADR 使用十個核心價值及工作定義，不沿用舊二十四項或同名異義的定義。
- [ ] 十個核心價值都需分類，類別內可排序及並列；自訂價值可分類、排序，結果獨立呈現並說明不參與情境對照。
- [ ] 取消原有比較賽，第一幕完成後直接進槽位 4：探索刺激／安全穩定。編寫一個具體變體，雙方都合理且有代價，不要求特定家庭或房產經驗。
- [ ] 二選一只有兩個選項，題面不揭露價值名稱，無強制倒數、逾時代答或第三選項。選取後須明確確認才構成答案。
- [ ] 可以返回修改並重新確認；未確認修改不覆寫舊答案，結果使用最後確認版本。
- [ ] 第一幕有明確先後且選擇方向明確時，結果可標相符／不同；第一幕並列時只描述選擇。透過不同作答路徑驗證兩種對照均能呈現。
- [ ] 簡短結果顯示第一幕分類、順序、並列及具體情境答案，不產生第二幕總分、總排名、名次差、人格診斷或真實行為判定。
- [ ] 開場交代自編反思工具、尚未驗證及假設性自我回報；不宣稱單題模式涵蓋十個價值或已達完整十五分鐘體驗。
- [ ] 這條路徑採編輯雜誌風的基本字體、色彩、直角及線分隔，支援鍵盤與觸控，不將拖曳設為唯一操作。
- [ ] 以瀏覽器外部行為驗收分類、並列、自訂價值、提交、回改與結果；按需加入最少的流程驗證工具，建置通過。避免建立只為測試私有狀態的介面。
- [ ] 必要的流程整理與舊比較賽路徑移除一併完成，保持這張票本身可建置及展示，不先建立獨立的水平架構工程。

## Blocked by

- None (can start immediately).
