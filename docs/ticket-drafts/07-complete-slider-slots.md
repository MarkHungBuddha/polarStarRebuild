# 07：補齊三個代價滑桿槽位

## What to build

使用者可在完整 MVP 所需的三個滑桿槽位遇到不同日常情境，從作答到結果都保留接受條件的原意。

## Acceptance criteria

- [ ] 將槽位 1（自主／安全穩定）補至兩變體，完成槽位 7（享受生活／成就）及 10（成就／普遍關懷）各兩變體；本票新增五題，滑桿共六題。
- [ ] 每題背景、刻度、單位、雙方代價及結果文案完整，兩邊皆合理；不將財務條件視為價值強度。
- [ ] 所有新增題目皆可從體驗流程作答、確認、返回修改並出現在結果中，沿用相同機制而非逐題客製程式。
- [ ] 接受條件題不產生價值勝負或相符／不同標示，不用作者設定的中點硬分方向。
- [ ] 新變體有全域唯一且穩定的識別，同槽機制一致；若保存與分享已完成，新增變體需自然遵守其契約。
- [ ] 透過代表性的新槽位驗證完整作答到結果路徑，並驗證新增內容的識別、機制與答案語意；完成建置。

## Blocked by

- 02：以代價滑桿表達接受條件。
- 03：加入刪稿並完成三關原型。

先完成三關原型，再擴充滑桿內容；不依賴分配機制或其他內容擴充票。
