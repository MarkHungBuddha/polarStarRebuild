# 04：中途離開後在本機續答

## What to build

使用者重新開啟同一瀏覽器後，可選擇繼續原本的題目與進度，或重新開始，也能清除紀錄；本機儲存失敗時仍可完成當次體驗。保存契約需能容納後續各種原始答案，不依賴某個機制的私有元件狀態。

## Acceptance criteria

- [ ] 保存第一幕分類、順序、並列、自訂價值、本次實際題目身分、已確認答案及進度。
- [ ] 重新載入後提供繼續／重新開始；繼續沿用原題目及確認版本，不重新抽題、不將答案套到其他題目。
- [ ] 未確認草稿不悄悄取代已確認答案；已有已確認答案的題目在續答及結果中保持一致。
- [ ] 提供清除本機作答紀錄的操作；重新開始不意外沿用舊答案。已看變體紀錄的行為需明確，不與未來新鮮感規則衝突。
- [ ] 儲存讀寫不可用或失敗時，清楚告知無法保存，但仍可完成當次流程。
- [ ] 避免損壞或不相容的保存資料造成錯題對答或應用程式崩潰；安全返回可重新開始的狀態，不宣稱已有跨版本遷移能力。
- [ ] 不加入帳號、遠端作答保存、統計端點或雲端同步。
- [ ] 經由重新載入、已確認／未確認修改、清除及模擬儲存失敗驗證使用者可見行為，並完成建置。
