# 03：加入刪稿並完成三關原型

## What to build

使用者能在槽位 2 的自主／遵守規範情境，從兩段合理回覆中刪掉一段並確認留下的回覆，結果忠實反映取捨。與滑桿票整合後，即可展示已約定的槽位 1、2、4 三關原型。

## Acceptance criteria

- [ ] 編寫槽位 2 的一個具體變體，兩段回覆完整合理，各保護不同價值並有明確代價，避免一段明顯失禮或不道德。
- [ ] 開始時兩段皆未選定；使用者刪掉一段、留下另一段後才能確認，不把未操作的草稿當成答案。
- [ ] 支援點選、鍵盤及觸控，畫刪除線可作視覺回饋，但不能要求畫線手勢才能作答。
- [ ] 結果呈現實際留下的回覆；只有符合共同對照規則才標示相符／不同。
- [ ] 返回修改與最後確認版本的行為與其他機制一致。
- [ ] 本票可先與既有二選一獨立展示；滑桿完成後，三關按槽位 1、2、4 順序可完整走到簡短結果，沒有未實作機制的占位題。
- [ ] 原型不宣稱涵蓋十個價值；不加入五人試玩或量化試玩門檻作為完成條件。
- [ ] 驗證未操作不能當作提交、刪稿確認、回改、並列時不硬判方向及鍵盤流程，並完成建置。
