# 06：完成三個時間分配槽位

## What to build

使用者能在三個時間分配槽位，分配情境給定的有限資源，確認後於結果看到實際配置及有依據的解讀。三關原型已完成後，擴充出第四種互動機制。

## Acceptance criteria

- [ ] 完成槽位 3（自主／照顧身邊的人）、6（探索刺激／成就）、14（安全穩定／普遍關懷），各兩個具體可玩變體，共六題。
- [ ] 每題清楚說明資源總量、單位、可分配項目及雙方代價；輸入不能超出可用資源，確認前清楚顯示實際配置。
- [ ] 支援鍵盤及觸控分配，不要求拖曳；預設配置不構成作答，須明確確認。
- [ ] 保存原始配置及題目身分；回改與最後確認版本的行為沿用既有路徑，能被既有保存與分享契約容納。
- [ ] 結果呈現實際配置；只有內容明確支持方向時才做對照。中立或方向不明時只描述，不把比例轉成價值強度。
- [ ] 題目、機制、解讀與可玩流程一起交付，不只是加入資料而無法從介面完成。
- [ ] 驗證有限資源限制、確認、回改、結果語意、鍵盤及手機操作；檢查六個變體識別與機制一致，並完成建置。

## Blocked by

- 03：加入刪稿並完成三關原型。
