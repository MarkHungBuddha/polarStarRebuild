# 05：分享同題並讓一般重測優先遇到新變體

## What to build

使用者可分享只重現題目的連結；相同 seed 與題庫版本重現同題及同順序，不受另一台瀏覽器的已看紀錄影響。一般重測則優先選未看過的變體，續答不改題。

## Acceptance criteria

- [ ] 為槽位 4 補上第二個有穩定識別的二選一變體，使固定抽題與重測新鮮感能透過真正不同的可玩題目驗證。
- [ ] 提供題目分享入口，分享網址只帶重現題目所需資訊，不包含第一幕排序、自訂價值、答案或結果。
- [ ] 相同指定 seed 與內容版本下，題目及順序固定；不同本機已看紀錄不改變分享題目。
- [ ] 一般重新測驗優先選未看過的變體；全部看過後仍可正常開始，不承諾每次絕不重複。
- [ ] 明確使用同一份本次題目紀錄供作答、續答及結果引用，避免頁面重算抽題造成中途換題。
- [ ] 題庫版本不可用時不悄悄拿同一 seed 對應到不同語意題目；向使用者說明並提供開始目前版本的路徑。
- [ ] 已看紀錄不可讀寫時可退回不依賴該紀錄的抽題，不阻擋完成；遵守本機保存失敗告知原則。
- [ ] 驗證不同已看紀錄下的固定題目與順序、分享網址不帶答案、一般重測優先未看變體，以及續答不重新抽題；完成建置。
