# 02：以代價滑桿表達接受條件

## What to build

使用者能在槽位 1 的自主／安全穩定情境，用滑桿表達接受條件，確認後在結果看到保留單位與語意的原始條件，並能返回修改。完成後體驗包含滑桿與既有二選一。

## Acceptance criteria

- [ ] 編寫槽位 1 的一個具體變體，說清背景、條件、刻度、單位及雙方代價；不把財務承受能力說成價值強度。
- [ ] 滑桿初始位置不構成作答；已確認答案與尚未確認的操作可區分。
- [ ] 保存並呈現原始條件，例如需要幾個月生活費，而非只保存無語意的正規化數值。
- [ ] 只表達接受條件時，不判哪個價值勝出、不標兩幕相符／不同、不增加權重。
- [ ] 返回修改後，結果只在再次確認後採用新條件；不改動其他已確認題目的答案。
- [ ] 沿用內容與機制分離的作答路徑，結果能同時呈現條件題與二選一的不同解讀方式。
- [ ] 支援鍵盤與觸控，滑桿操作區至少四十四像素，確認操作清楚可見。
- [ ] 驗證預設值未提交、明確確認、修改後結果與條件文案；確認沒有強度或勝負推論，並完成建置。
