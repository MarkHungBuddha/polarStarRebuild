# 結果頁以兩份前三名作結

原本結果頁只逐題呈現證據，做完沒有可帶走的結論。專案負責人決定使用者應帶走「自己的前三名價值」，並用情境作答檢驗這個排序是否是自己真的想要的，進而重新思考或規劃生活。因此結果頁開頭並列第一幕自述的前三名與第二幕最常選的前三名，取代原先「不建立第二幕總排名」的限制。

第二幕只數明確選邊的答案，排序就是選擇次數，不做強度加權、Bradley–Terry 或跨幕名次差。每個價值一次約只出現三題，所以名次一律附上「選了 N 次／共 M 題」，並說明單題即可改動名次；並列者同列呈現，不另行打破並列；結論仍是反思材料，不是測驗分數或人格判定。

> 適用範圍（2026-10-26）：兩份前三名的結論形式仍有效；第二幕「只數選邊次數」已由 [ADR 0006](0006-explicit-preference-strength.md) 的偏向分數取代，只用於讀取已發布的格式版本 1 結果連結。每個價值在一次作答中固定出現三題。
