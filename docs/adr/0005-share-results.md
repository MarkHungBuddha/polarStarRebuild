# 開放分享結果，結果只存在網址

原規格把「答案／結果分享」列為不做，分享連結只重現題目，理由是答案只保存在本機，不加入帳號、遠端儲存或統計端點。專案負責人在 2026-10-24 決定推翻這一條：作答者可以分享結果，但結果只存在網址本身，網站仍然不上傳、不保存任何人的作答。

公開範圍只到兩份前三名、名次、並列和第二幕的「選了 N 次／共 M 題」，自訂價值要分享者逐項勾選才放。結果連結帶的是分享當時算好的結論，不帶逐題答案，開啟時也不重算：把原始答案放進網址，即使介面不顯示，收件者也能解碼取得；重算則會讓同一條連結隨題庫改版得到不同結果。網址可以被竄改，網站不做簽章；收件者頁註明這是分享者自己作答的結果，格式檢查不稱為驗證或防偽。

這個決定帶來兩項永久承諾，要撤回任何一項都得另寫決策記錄：

1. **核心價值 id 永久不刪、不挪作他用。** 結果連結存的是英文 id（`autonomy`、`care`…），開啟時顯示目前的名稱。只改措辭時舊連結顯示新名稱；概念本身改了就換新 id，舊 id 留著，名稱凍結在舊的寫法。
2. **發布過的結果格式永久保留解讀能力。** 結果格式版本是一個整數，和 `catalogVersion` 分開，只有欄位或編碼改了才升版。每個發布過的版本都要能讀，並由定版範例連結的測試守著。

題庫改版不影響舊結果的顯示，只影響能不能再做同一份題目：`v` 和目前的題庫版本相同才提供「用同一份題目作答」，不同就說明這份結果用的是舊版題目，改提供「用目前題目開始」。

細節與依據見[結果分享規格](../result-share-spec.md)和地圖 [#25](https://github.com/MarkHungBuddha/polarStarRebuild/issues/25) 的決策票。
