# 滑桿與部分分配也算偏向

ADR 0002 的前三名原本只數二選一、刪稿與全數分配，實際跑一輪後每個名次只靠一到三題，常有價值完全沒有可計的題目。為讓前三名有更多題目支撐，分配題改以較多的一方為偏向，滑桿題改以每題作者設定的兩個門檻判斷：低於下門檻偏向一方、高於上門檻偏向另一方，兩門檻之間不算偏向。相符／不同的標示沿用同一套偏向，讓逐題證據與前三名一致。

門檻是對已確認原始數值的解讀，因此放在 `src/scenarios/slider-leans.ts`，不進入題庫版本雜湊，調整門檻不會讓既有分享連結或續答失效。差距大小仍不代表強度；結果頁同時顯示門檻，讓使用者能核對。門檻由 agent 提出，專案負責人已採用。
