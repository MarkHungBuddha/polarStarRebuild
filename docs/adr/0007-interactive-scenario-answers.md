# 第二幕以情境操作作答

狀態：已實作並上線（2026-10-26，#59 的子票 #60–#71），取代 [ADR 0006](0006-explicit-preference-strength.md)。

2026-10-26 試玩後，使用者指出統一五段量表讓原本的互動體驗變成純問卷，確認第二幕所有題目改以操作情境中的物件或資源作答，畫面須呈現操作造成的取捨與代價；只把五個選項改成滑桿不符合這次需求。操作本身就是答案，不在操作後再強制作答五段偏向；允許重新設計結果整理方式，不將不同操作硬換算為既有的 0／1／2 分。

第一幕的價值分類與排序暫時不調整。結果正文呈現結果與具體作答依據，詳細規則移到可展開的「結果怎麼整理」。

使用者重新說明產品目的後，確認保留兩幕排名與逐題對照：第一幕呈現認為重要的價值，第二幕呈現本輪情境中較常優先保留的價值，同次數並列。不同互動的原始數值不能直接加總，因此題目須先形成可解讀的決策，再設計操作方式；只詢問接受條件的題目可改為固定條件下的決策，不直接由接受條件推算偏向方向或強度。

共同計數採每題最多 1 次：明確選定方案，或同種有限資源分配較多的一側，記為優先保留；平均分配與主動確認的「目前無法決定」不判方向。每個價值有三次出題機會，最多記 3 次，不以差距加權；結果保留原始決策、明確決策題數與資料不足提示，全部無法判方向時不產生排名。這是本輪決策的整理約定，不是價值重要性或偏好強度的測量。

第二幕定位為貼近生活的情境模擬，逐題對照才是發現差異的主要依據，不以模擬作答判定真實生活中的言行矛盾。結果後提供自願填寫的反思筆記，協助回想情境條件、原先排序或下次做法，保留第一幕原始紀錄。

題庫維持 15 組取捨、每組 3 個變體，每輪抽 15 題，45 題全部改成互動題。第一幕可相容的答案保留，舊版第二幕須重新作答；已發布的結果連結維持原本解讀，不將舊答案換算成新答案。

新結果連結使用格式版本 3：版本 1 雖然同樣數選邊次數，但沒有平均分配與無法決定的狀態，沿用會讓舊連結的意思改變。

45 個互動變體由 agent 起草，專案負責人在 2026-10-26 審閱通過三批內容後切換正式入口：首頁只提供互動作答，五段偏向作答與開發預覽入口都已移除。完整設計與驗收條件見 [互動情境題規格](../interactive-scenario-spec.md)。
