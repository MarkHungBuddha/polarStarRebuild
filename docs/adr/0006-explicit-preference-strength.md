# 情境題直接詢問偏向程度

狀態：已被 [ADR 0007](0007-interactive-scenario-answers.md) 取代（2026-10-26，#71）。五段偏向作答已移除；本 ADR 只說明格式版本 2 結果連結的計分意思。

完整需求與實作同步更新項目見 [五段偏向作答規格](../preference-strength-spec.md)。

2026-10-26 訪談確認：所有情境題改為由使用者自行表達五段偏向程度，移除二選一與刪掉一個選項的作答方式，讓使用者能表達取捨的方向與程度。強烈偏向給該側 2 分，稍微偏向給該側 1 分，兩者相當則兩側都不加分；這是產品計分約定，不表示偏好強度具有兩倍關係。

排名只按總分，同分並列，零分不列入名次；全部零分時不產生排名。新題型取代了 ADR 0003 的滑桿門檻與分配量計分方式；既有接受條件的數值仍不能直接解讀為偏好強度，也不能據此換算新答案。

舊版未完成作答須重新開始；舊結果連結保留原本次數與排名並標明舊版計分，新結果使用新版分享格式，避免混淆兩種計分意義。無法重現的舊題目連結須說明原因，提供開始新版測驗的入口。此決定已確認，並在 #49–#56 實作：2026-10-26 起首頁只提供五段偏向作答，ADR 0003 的滑桿門檻與分配計分隨舊作答移除。
