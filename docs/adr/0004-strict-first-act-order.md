# 第一幕不再允許並列

原本第一幕類別內可以並列，價值一開始全部並列在第 1 位，只有使用者自己排出的先後才拿來標示相符／不同。改成拖曳排序後，專案負責人決定取消並列：類別內一定要排出先後，即使難以區分也須排出。

排序頁一開始照價值加入類別的順序排好（依序分類時就是清單順序）。使用者沒有拖動就進入第二幕時，這個順序也算是使用者排的，結果照常標示相符／不同。這表示沒有調整排序的人，比對的是清單原本的順序；專案負責人接受這個取捨，換來每一題都能對照第一幕。

換類別的價值排到新類別最後，兩個類別的位置都重新編成 1 到 n。答案格式不變；取消並列前保存的紀錄可能仍有並列，在排序頁移動任何價值或按「進入情境中的取捨」時，所有類別都照畫面上的順序重新編號；沒有再回到排序頁的舊紀錄，結果頁照舊只描述那些題目的答案。
