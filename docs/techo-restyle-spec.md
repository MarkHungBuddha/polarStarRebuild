# 北極星：261024 手帳感視覺調整

## Problem Statement

現有網站已提供兩幕價值反思、十五題情境、作答保存與結果回顧，但介面尚未套用 261024 手帳感設計。使用者希望全流程具有一致的紙張、手寫標題與墨水配色，同時保留既有操作和作答結果。

參考設計只涵蓋首頁、二選一示意與結果頁，且部分示意與目前產品不同：第一幕沒有設計稿，其他題型有各自的操作，結果則需要兩份前三名及完整證據。直接照搬示意會遺失功能或改變結果解讀。

## Solution

將手帳感視覺套用到完整產品，包括首頁、第一幕分類與排序、所有情境題型、結果摘要與詳細回顧。沿用現有題型、確認答案流程、計分與資料行為；以共用配色、字體、紙卡及控制元件樣式統一體驗。

提供淺色、深色與跟隨系統三種主題選擇並記住偏好。手機使用單欄；桌面依內容保留排序、比較與複雜操作所需的空間。首頁提供簡短說明與可開關的「關於這份題目」，保留題目分享連結。

## User Stories

1. 作為初次使用者，我希望首頁清楚介紹兩幕流程，以便了解接下來會做什麼。
2. 作為使用者，我希望全流程具有一致的手帳感，以便自然地閱讀與操作。
3. 作為使用者，我希望內文與控制元件容易閱讀，以便不受裝飾影響。
4. 作為使用者，我希望預設主題跟隨系統，以便符合裝置的顯示偏好。
5. 作為使用者，我希望手動選擇淺色或深色，以便使用自己舒適的配色。
6. 作為使用者，我希望隨時恢復跟隨系統，以便主題隨系統設定更新。
7. 作為回訪使用者，我希望網站記住主題偏好，以便不必每次重選。
8. 作為使用者，我希望開啟網站時就顯示正確主題，以便避免明顯閃爍。
9. 作為無法使用本機儲存的使用者，我希望仍能閱讀及操作網站，以便不因偏好儲存失敗而受阻。
10. 作為使用者，我希望展開完整的題目說明，以便了解工具依據與限制。
11. 作為使用者，我希望關閉說明後留在原流程，以便繼續操作。
12. 作為第一幕使用者，我希望保留分類按鈕，以便表達價值的重要性。
13. 作為第一幕使用者，我希望保留名次選單及並列，以便表達相同的重要程度。
14. 作為第一幕使用者，我希望保留自訂價值，以便記錄預設清單以外的想法。
15. 作為二選一題使用者，我希望保留既有移動及點選操作，以便做出取捨。
16. 作為刪稿題使用者，我希望保留既有刪稿操作，以便表達要留下的選擇。
17. 作為滑桿題使用者，我希望保留存錢筒、時鐘、月曆等既有控制方式，以便調整接受條件。
18. 作為分配題使用者，我希望保留活動配置與調整方式，以便安排有限資源。
19. 作為作答者，我希望確認後才提交答案，以便預設值或草稿不被誤認為作答。
20. 作為作答者，我希望返回修改時保留先前答案，以便重新考慮選擇。
21. 作為作答者，我希望看見目前題號與進度，以便掌握剩餘流程。
22. 作為中途離開的使用者，我希望原有紀錄仍可續答，以便接續先前的分類、排序與答案。
23. 作為回訪使用者，我希望原有題組及已看題目紀錄維持相同行為，以便續答與重測不受改版干擾。
24. 作為結果頁使用者，我希望看見兩幕各自的前三名與並列，以便比較兩份作答。
25. 作為結果頁使用者，我希望保留選擇次數、分母及解讀提醒，以便了解排名的限制。
26. 作為結果頁使用者，我希望能查看逐題證據並修改答案，以便核對結果與自己的想法。
27. 作為使用者，我希望繼續分享不含答案的題目連結，以便邀請別人作答相同題組。
28. 作為使用者，我希望重新開始與清除本機作答紀錄仍有原有差異，以便自行決定保留哪些紀錄。
29. 作為手機使用者，我希望窄螢幕不需橫向捲動，以便閱讀長價值名稱與操作題目。
30. 作為桌面使用者，我希望分類、排名比較與複雜題型有足夠空間，以便不必在過窄欄位中操作。
31. 作為鍵盤使用者，我希望保留各流程的鍵盤操作與清楚焦點，以便完成整份反思。
32. 作為偏好減少動態效果的使用者，我希望介面停止位移動畫，以便舒適地使用網站。

## Implementation Decisions

- 共用視覺樣式統一使用設計 token，涵蓋淺深色、紙張、文字、墨水、裝飾、控制元件、焦點與停用狀態。預設使用藍墨水與粉色紙膠帶。
- 手寫字採 LXGW WenKai TC，用於標題、短情境及註記；內文與控制元件使用 Noto Sans TC 及合理備援。超過三行的長段落使用無襯線字，中文不使用負字距。沿用目前的 Google Fonts 載入方式，不假設已有自架字型流程。
- 點格紙、紙膠帶、貼紙與螢光筆依參考規格使用；每個畫面最多一條紙膠帶與一個貼紙。只旋轉背景及裝飾，文字維持水平。
- 主題控制涵蓋跟隨系統、淺色、深色；預設跟隨系統。手動偏好可保存，恢復跟隨系統後應回應系統主題變更。讀寫儲存失敗時回到可用的系統預設，不影響作答。
- 主題偏好獨立於作答資料，在畫面初次呈現前套用，避免先顯示錯誤主題。現有作答資料不需要遷移。
- 首頁保留簡短工具說明；完整限制放入可開關且可用鍵盤操作的說明區，不新增獨立路由。結果頁仍保留與次數及排名解讀直接相關的提醒。
- 首頁與一般情境採窄欄；第一幕、結果頁與需要較大操作空間的題型保留適合桌面的寬度。手機一律採可操作的單欄，不將全站桌面寬度固定為 440px。
- 第一幕保留分類按鈕、名次選單、並列及自訂價值。第二幕保留全部題型、操作與確認方式；設計稿的單選卡片不取代現有互動。
- 結果保留摘要及詳細回顧、兩份前三名、並列、次數與分母、逐題證據及修改流程。沿用既有偏向判定，不以視覺長條推導新分數或名次差。
- 題庫、計分、答案結構、題組版本、抽題、已看紀錄、續答、題目分享及紀錄清除均維持原有行為。新增主題設定不改變題組分享內容。
- 介面用詞沿用既有詞彙與決策：情境中的取捨仍是自我回報，作答差異不等同於真實行為或人格判定。
- 可點擊區至少 44 × 44px，進度同時有文字與可讀取數值，焦點清楚可見。減少動態效果時停用位移動畫。

## Testing Decisions

使用者已確認：沿用 Playwright 的瀏覽器驗收入口，測試可見行為；另以手機／桌面及淺／深色畫面檢查排版，不新增元件內部測試。

### 既有驗收基礎

沿用既有完整十五題流程、具體操作、分類排序、各題型、結論、續答與分享測試及共用 fixtures。固定題組與輸入以便比較改版前後結果；不因 CSS 或元件拆分而重寫行為預期。必要的選取器調整應維持原測試意圖。

### 新增與延伸的驗收

- 主題：系統預設、手動覆寫、重新載入後保留、恢復跟隨系統、系統設定改變及儲存失敗時皆可使用。切換主題不更動答案或作答位置。
- 說明區：可開關、鍵盤可操作、展開狀態可辨識，操作後仍可開始或接續作答；首頁保留簡短說明，結果仍可見必要限制。
- 視覺：320px、390px 與代表性桌面寬度下，檢查首頁、分類、排序、所有題型、結果摘要及詳細內容；包含淺深色、長價值名稱、自訂價值、並列、續答與錯誤提示。
- 操作：保留各題型的點選、拖曳及鍵盤能力，未確認答案不被提交，返回修改與結果更新符合既有行為。
- 相容性：使用既有儲存與分享測試驗證續答、同題連結、損壞紀錄、已看紀錄及清除行為，不為視覺改版更換資料格式或版本。
- 可及性與呈現：無橫向溢出、文字不截斷、焦點可見、點擊區尺寸符合要求；進度可讀取、減少動態效果時無位移。核對設計配色的文字對比及字型載入後的實際排版。
- 首次載入與字型：檢查主題套用時序及慢速字型載入的備援顯示，避免錯誤主題閃爍、空白文字或無法操作。

測試應驗證使用者能完成什麼、能看到什麼，不斷言內部 state、元件名稱或 token 的實作方式。截圖用於視覺比對，不以通過功能測試代替視覺驗收。完成時執行專案既有型別、lint 與完整測試檢查；工程驗收不代表完成使用者試玩或心理測量驗證。

## Out of Scope

- 自訂墨水色、紙膠帶色的設定介面。
- 結果圖片匯出、圖片尺寸與分享卡設計。
- 新題型、第三選項、自動換題、第一幕拖曳排序或以單選卡片取代既有操作。
- 新計分方式、單一主價值、前五名長條或最大落差解讀。
- 修改題目內容、核心價值定義、答案與儲存格式、題組版本及分享協定。
- 新增獨立說明頁路由、後端服務、帳號或雲端同步。
- 自架字型或子集化建置流程。
- 本次規格工作不包含直接實作、部署或建立拆分後的工作項目。

## Further Notes

範圍已於 2026-10-24 確認，驗收入口亦已獲使用者同意。視覺參考為 261024 手帳感 UI 規格及六張淺深色畫面；本規格記錄的範圍調整優先於參考稿中的示意功能。

結果解讀遵循既有「兩份前三名」及「滑桿與部分分配也算偏向」決策，不重新開啟已確認的領域選擇。第一幕與設計稿未涵蓋的題型由既有操作延伸視覺設計，實作驗收時一併檢查。

專案既有追蹤方式是 GitHub Issues，發布時使用 ready-for-agent 標籤。本規格可作為後續工作項目的共同來源。
